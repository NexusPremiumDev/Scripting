=====================================================
            EXECUTOR INSTALLATION GUIDE
=====================================================

Due to how the software operates (Roblox memory injection), 
Windows Defender may trigger a False Positive warning. 
You need to add a folder exclusion to prevent it from being deleted.

Detailed Step-by-Step Installation Video:
https://www.youtube.com/@NexusRbx99 - https://www.youtube.com/watch?v=pKuxcKsFVvM

Quick Setup Steps:
1. Open Windows Security > Virus & threat protection settings.
2. Scroll down to "Exclusions" under "Manage settings".
3. Click "Add or remove exclusions".
4. Select "Folder" and choose the folder where this executor is located.
5. Launch the program and enjoy!

=====================================================
            EXECUTOR KURULUM KILAVUZU
=====================================================

Yazılımın çalışma şekli (Roblox bellek enjeksiyonu) nedeniyle, 
Windows Defender hatalı bir tehdit uyarısı (False Positive) verebilir. 
Programın silinmesini önlemek için bir klasör dışlama kuralı eklemeniz gerekir.

Ayrıntılı Adım Adım Kurulum Videosu bu kanalda:
https://www.youtube.com/@NexusRbx99 - https://www.youtube.com/watch?v=pKuxcKsFVvM

Hızlı Kurulum Adımları:
1. Windows Güvenliği > Virüs ve tehdit koruması ayarları'nı açın.
2. "Ayarları yönet" başlığı altındaki "Dışlamalar" kısmına kadar aşağı kaydırın.
3. "Dışlamaları ekle veya kaldır" seçeneğine tıklayın.
4. "Klasör"ü seçin ve bu executor'ın bulunduğu klasörü belirleyin.
5. Programı başlatın ve keyfini çıkarın!
